### 🛠️ Homelab & Network Architecture

- **Edge Routing & Switching:** MikroTik RouterOS handling WAN failover, static DHCP reservations, and isolated VLAN boundaries.
- **Virtualization & Compute:** Proxmox VE running Debian & Rocky Linux VMs for isolated Docker container stacks.
- **Zero-Trust Ingress & Access:** Tailscale Mesh VPN for encrypted remote administration + Cloudflare Tunnels for web ingress without open router ports.
- **Local DNS & Security:** AdGuard Home & Pi-hole DNS sinkholes filtering telemetry and ad traffic network-wide.
- **Monitoring & Backup:** Uptime Kuma tracking service availability alongside local RAID arrays for data redundancy.
