### 🛠️ Homelab & Setup Overview

- **Routers & Switches:** MikroTik hardware managing home traffic and keeping services cleanly separated.
- **Servers & Storage:** Proxmox VE running Linux virtual machines and Docker containers.
- **Remote Access:** Tailscale Mesh VPN and Cloudflare Tunnels for secure connection without open ports.
- **Privacy & DNS:** AdGuard Home and Pi-hole for network-wide ad blocking.
